Before you start, ensure these are deployed and healthy:

----

* `external-secrets`
* `rhdh-gitops`
* `keycloak`
* `rbac`
* `devspaces`
* `trusted-artifact-signer`
* `backstage-bootstrap`

Prepare two browser tabs:

. ArgoCD: https://openshift-gitops-server-openshift-gitops.{openshift_cluster_ingress_domain}[ArgoCD^]
. Developer Hub: https://backstage-rhdh.{openshift_cluster_ingress_domain}[Developer Hub^]

== Act 3: How It All Works — The GitOps Engine [8 min]

[TIP]
====
Switch to ArgoCD. Now peel back the curtain.
====

=== Step 1: ArgoCD Overview [2 min]

Open: https://openshift-gitops-server-openshift-gitops.{openshift_cluster_ingress_domain}[ArgoCD^]

* "Everything you just saw was deployed by ArgoCD — including ArgoCD itself."
* Show the list of Applications — "Each tile is a platform component, deployed from a Helm chart in Git."
* Click on one (e.g., `keycloak`) — Show the resource tree: "ArgoCD renders the Helm chart and reconciles every resource."

=== Step 2: Anatomy of a Deployment [2 min]

Show a terminal and display an ArgoCD Application:

[source,bash,subs="attributes"]
----
oc get application openshift-pipelines -n openshift-gitops -o yaml | head -30
----

* "This is the entire deployment definition. A source (Helm chart in Git) and a destination (namespace). That's it."
* "No `helm install`. No manual steps. Git is the source of truth."

=== Step 3: The Helm Chart Repository [2 min]

* "All components come from a single Helm chart repository."
* Show the repo: {helm_repo}[{helm_repo}^] (branch: `{helm_repo_tag}`)
* "Each folder is a component: `keycloak/`, `external-secrets/`, `redhat-developer-hub/`, etc."
* "Want to change something? Update the chart, push to Git, ArgoCD reconciles."

=== Step 4: Two ArgoCD Instances [2 min]

* "We use two ArgoCD instances: one for the **platform** (openshift-gitops), one for **developer apps** (rhdh-gitops)."
* Open: https://rhdh-gitops-server-rhdh-gitops.{openshift_cluster_ingress_domain}[RHDH GitOps^]
* "When a developer creates an app from a template, the ArgoCD Application lands here — not in the platform GitOps."
* "Separation of concerns: platform team owns platform GitOps, developers deploy through the portal."

== Act 5: Live Deployment [5 min]

[TIP]
====
Deploy one component live to prove it takes seconds.
====

Pick a component that isn't deployed yet (or delete one before the demo). For example, delete and redeploy `external-secrets`:

[source,bash,subs="attributes"]
----
oc delete application external-secrets -n openshift-gitops
----

Wait a moment, then redeploy:

[source,bash,subs="attributes"]
----
cat <<'EOF' | oc apply -f -
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: external-secrets
  namespace: openshift-gitops
spec:
  project: default
  source:
    repoURL: {helm_repo}
    targetRevision: {helm_repo_tag}
    path: external-secrets
    helm:
      values: |
        vault-integration:
          vault:
            namespace: vault
            name: vault
            auth:
              namespace: default
  destination:
    server: https://kubernetes.default.svc
    namespace: external-secrets
  syncPolicy:
    automated:
      prune: true
      selfHeal: true
    syncOptions:
    - CreateNamespace=true
EOF
----

Switch to ArgoCD UI and watch it sync in real time.

* "That's it. One YAML, applied to the cluster. ArgoCD does the rest."
* "This is how we deployed every component — in under 2 hours."
