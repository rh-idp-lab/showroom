= Admin Deployment Runbook
:navtitle: Admin Deploy (1-shot)

[NOTE]
====
*Admin page — not intended for participants.* +
Deploys the entire lab with 2 copy-pastes.
Prerequisites: GitLab, Vault, Keycloak, NooBaa, and OpenShift GitOps are already deployed by Ansible.
====

== Prerequisite (manual): GitLab OAuth App for DevSpaces

. Open https://gitlab-gitlab.{openshift_cluster_ingress_domain}[GitLab^] as `root` / `{common_password}`
. *Avatar → Edit profile → Applications → Add new application*:
** Name: `devspaces`
** Redirect URI: `\https://devspaces.{openshift_cluster_ingress_domain}/api/oauth/callback`
** Scopes: `api`, `read_user`, `read_repository`, `write_repository`, `openid`, `profile`, `email`
. Save and copy the **Application ID** and **Secret**

== Block 1 — Retrieve credentials

[source,bash,subs="attributes"]
----
# GitLab root token
export GITLAB_TOKEN=$(oc get secret root-user-personal-token -n gitlab \
  -o jsonpath='{.data.token}' | base64 -d)

# ArgoCD password
export ARGOCD_PASSWORD="{common_password}"

# Keycloak: retrieve the backstage client secret
export KEYCLOAK_TOKEN=$(curl -sk -X POST \
  "https://sso.{openshift_cluster_ingress_domain}/realms/master/protocol/openid-connect/token" \
  -d "client_id=admin-cli&username=admin&password={common_password}&grant_type=password" \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['access_token'])")

export CLIENT_UUID=$(curl -sk \
  -H "Authorization: Bearer $KEYCLOAK_TOKEN" \
  "https://sso.{openshift_cluster_ingress_domain}/admin/realms/sso/clients?clientId=backstage" \
  | python3 -c "import sys,json; print(json.load(sys.stdin)[0]['id'])")

export KEYCLOAK_CLIENT_SECRET=$(curl -sk \
  -H "Authorization: Bearer $KEYCLOAK_TOKEN" \
  "https://sso.{openshift_cluster_ingress_domain}/admin/realms/sso/clients/$CLIENT_UUID/client-secret" \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['value'])")

# DevSpaces GitLab OAuth (created in the prerequisite step above)
export GITLAB_OAUTH_ID=<Application ID>
export GITLAB_OAUTH_SECRET=<Secret>

echo "GITLAB_TOKEN:           $GITLAB_TOKEN"
echo "KEYCLOAK_CLIENT_SECRET: $KEYCLOAK_CLIENT_SECRET"
echo "GITLAB_OAUTH_ID:        $GITLAB_OAUTH_ID"
----
