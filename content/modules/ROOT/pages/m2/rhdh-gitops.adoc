= Deploy a Dedicated ArgoCD Instance
:navtitle: Deploy a Dedicated ArgoCD Instance

== Why a separate ArgoCD instance

The cluster GitOps ArgoCD (in `openshift-gitops`) manages platform components. A separate ArgoCD instance in `rhdh-gitops` is used for developer applications. This separation provides:

* Clear boundary: platform team owns cluster GitOps; developers use app GitOps
* Different RBAC and access control per instance
* Isolation so developer deployments do not affect platform stability

== The Helm Chart

The ArgoCD Application points to the `gitops` chart in your GitLab repository.
Browse it here: {helm_repo_browse}/-/tree/{helm_repo_tag}/gitops[{helm_repo_browse}/-/tree/{helm_repo_tag}/gitops^]

The chart deploys a dedicated ArgoCD instance (`ArgoCD` CR) with its RBAC, routes, and resource customizations pre-configured.

== Create the ArgoCD Application

Create the ArgoCD Application YAML that deploys the dedicated ArgoCD instance:

[source,bash,subs="attributes"]
----
cat <<'EOF' > rhdh-gitops-application.yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: rhdh-gitops
  namespace: openshift-gitops
  finalizers:
    - resources-finalizer.argocd.argoproj.io/foreground
spec:
  destination:
    server: https://kubernetes.default.svc
    namespace: rhdh-gitops
  project: default
  source:
    repoURL: {helm_repo}
    targetRevision: {helm_repo_tag}
    path: gitops
    helm:
      values: |
        nameOverride: rhdh-gitops
        password: {common_password}
        controller:
          resources:
            requests:
              cpu: 500m
              memory: 1Gi
            limits:
              cpu: 1500m
              memory: 3Gi
  syncPolicy:
    automated:
      prune: true
      selfHeal: true
    retry:
      backoff:
        duration: 5s
        factor: 2
        maxDuration: 3m0s
      limit: 2
    syncOptions:
      - CreateNamespace=true
      - RespectIgnoreDifferences=true
EOF
----

== Apply the Application

[source,bash,subs="attributes"]
----
oc apply -f rhdh-gitops-application.yaml
----

== Verify

Confirm the application syncs in ArgoCD UI and check pods:

[source,bash,subs="attributes"]
----
oc get pods -n rhdh-gitops -w
----

== Access the new ArgoCD

Once deployed, the dedicated ArgoCD UI is available at:

link:https://rhdh-gitops-server-rhdh-gitops.{openshift_cluster_ingress_domain}[RHDH GitOps^]

Click **LOG IN VIA OPENSHIFT** and log in with `admin` / `{ocp_admin_password}`.
