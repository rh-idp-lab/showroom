= Import Software Templates (Golden Paths)
:navtitle: Import Software Templates

The portal is live and the catalog is populated. Software Templates are the last piece: opinionated scaffolding workflows that create repositories, pipelines, and ArgoCD applications from a single form. They encode platform best practices into reusable golden paths: the ultimate self-service experience.

.Platform Engineering Principle: Golden Paths, Not Golden Cages
****
A Software Template is the embodiment of a golden path. It bundles everything a developer needs to start shipping: a Git repository, a Tekton pipeline, an ArgoCD application, a Quay image tag, and a Vault secret reference — all created from a single form fill. The "right way" to build a service at Golden Path Inc. is also the easiest way. Developers are not forced into it, but they have no reason to look elsewhere.
****

You will now register a pre-built collection of templates from your GitLab repository into the Developer Hub catalog.

== The templates Location file

The file https://gitlab-gitlab.{openshift_cluster_ingress_domain}/rhdh/opencodequest-templates/-/blob/main/scaffolder-templates/opencodequest-templates.yaml[opencodequest-templates.yaml^] is a Backstage `Location` entity that references four ready-to-use scaffolder templates:

* *fight-ui*: Quarkus + web UI frontend service
* *quarkus-postgresql*: Quarkus CRUD microservice with a PostgreSQL database
* *quarkus-with-spring-postgresql*: Full pipeline with Tekton manifests
* *quarkus-ai*: AI-enabled Quarkus application

== Register the templates

. In Developer Hub, click **Self Service** in the left menu.
. Click **Import an existing Git repository**.
. Paste the following URL in the *Repository URL* field:
+
[source,subs="attributes"]
----
https://gitlab-gitlab.{openshift_cluster_ingress_domain}/rhdh/opencodequest-templates/-/blob/main/scaffolder-templates/opencodequest-templates.yaml
----
. Click **Analyze**, then **Import**.

Developer Hub will register the `Location` entity and automatically discover all four templates referenced by it.

== Verify

. Navigate to **Self Service** in the left menu.
. You should now see the four OpenCodeQuest templates available for use.

Templates are now registered in the catalog. Continue to xref:m6/services.adoc[Create Services] to deploy your first components.
