You have deployed all the platform services: GitOps, CI/CD pipelines, secrets management, SSO, a cloud IDE, and supply chain signing. Now it is time to tie them all together with a **developer portal**.

Red Hat Developer Hub (RHDH) is Red Hat's supported distribution of Backstage. It acts as the **single gateway** to your entire Internal Developer Platform — the one place where developers discover services, browse APIs, read documentation, and instantiate golden-path templates. It integrates with every service you have deployed so far:

* **Keycloak** — SSO authentication (Module 3)
* **GitLab** — source code discovery and repository creation (pre-installed)
* **ArgoCD** — application deployment status (Module 2)
* **OpenShift Pipelines** — pipeline run visibility (Module 2)
* **External Secrets / Vault** — secrets injection (Modules 2 & 3)
* **Dev Spaces** — one-click cloud IDE links (Module 4)
* **Trusted Artifact Signer** — signed artifact verification (Module 5)

== The Helm Chart

The ArgoCD Application points to the `redhat-developer-hub` chart in your GitLab repository.
Browse it here: {helm_repo_browse}/-/tree/{helm_repo_tag}/redhat-developer-hub[{helm_repo_browse}/-/tree/{helm_repo_tag}/redhat-developer-hub^]

The chart installs the Developer Hub operator (via OLM) and a `Backstage` instance pre-configured with plugins, catalog sources, and integrations for GitLab, Keycloak, ArgoCD, Vault, Quay, and Dev Spaces.

== Step 1 — Retrieve required credentials

[source,bash,subs="attributes"]
----
export GITLAB_TOKEN=$(oc get secret root-user-personal-token -n gitlab -o jsonpath='{.data.token}' | base64 -d)

# Retrieve the Keycloak client secret for the 'backstage' client
export KEYCLOAK_TOKEN=$(curl -sk -X POST \
  "https://sso.{openshift_cluster_ingress_domain}/realms/master/protocol/openid-connect/token" \
  -d "client_id=admin-cli&username=admin&password={common_password}&grant_type=password" \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['access_token'])")

export CLIENT_UUID=$(curl -sk \
  -H "Authorization: Bearer $KEYCLOAK_TOKEN" \
  "https://sso.{openshift_cluster_ingress_domain}/admin/realms/sso/clients?clientId=backstage" \
  | python3 -c "import sys,json; print(json.load(sys.stdin)[0]['id'])")

export KEYCLOAK_CLIENT_SECRET=$(curl -sk \
  -H "Authorization: Bearer $KEYCLOAK_TOKEN" \
  "https://sso.{openshift_cluster_ingress_domain}/admin/realms/sso/clients/$CLIENT_UUID/client-secret" \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['value'])")
----

== Step 2 — Create the ArgoCD Application

[source,bash,subs="specialcharacters,attributes"]
----
cat <<EOF > backstage-bootstrap-app.yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: backstage-bootstrap
  namespace: openshift-gitops
  finalizers:
    - resources-finalizer.argocd.argoproj.io/foreground
spec:
  project: default
  source:
    repoURL: {helm_repo}
    path: redhat-developer-hub
    targetRevision: {helm_repo_tag}
    helm:
      values: |
        redhat-developer-hub-prereqs:
          namespace: rhdh
          backstage:
            gitlab:
              token: $GITLAB_TOKEN
            oauth:
              clientId: backstage
              clientSecret: $KEYCLOAK_CLIENT_SECRET

        redhat-developer-hub-config-template:
          nameOverride: "backstage"
          namespace: rhdh
          gitlab:
            host: gitlab-gitlab.{openshift_cluster_ingress_domain}
            rootPassword: {common_password}
          backstage:
            host: backstage-rhdh.{openshift_cluster_ingress_domain}
          keycloak:
            host: sso.{openshift_cluster_ingress_domain}
            realm: sso
            clientId: backstage
            clientSecret: $KEYCLOAK_CLIENT_SECRET
          gitops:
            host: openshift-gitops-server-openshift-gitops.{openshift_cluster_ingress_domain}
          kubernetes:
            api: https://kubernetes.default.svc
          cluster:
            subdomain: {openshift_cluster_ingress_domain}

        redhat-developer-hub-application:
          gitops:
            namespace: openshift-gitops
          helm:
            values:
              git:
                host: gitlab-gitlab.{openshift_cluster_ingress_domain}
  destination:
    server: https://kubernetes.default.svc
    namespace: rhdh
  syncPolicy:
    automated:
      prune: true
      selfHeal: true
    syncOptions:
      - CreateNamespace=true
EOF
----

Apply it:

[source,bash]
----
oc apply -f backstage-bootstrap-app.yaml
----

== Verify

=== Verify in ArgoCD UI

Open the ArgoCD UI and confirm the `backstage-bootstrap` application syncs successfully and shows **Healthy** status.

ArgoCD link: https://openshift-gitops-server-openshift-gitops.{openshift_cluster_ingress_domain}/applications/backstage-bootstrap[Backstage Bootstrap Application in ArgoCD^]

=== Verify in the OpenShift Console

. Open the https://console-openshift-console.{openshift_cluster_ingress_domain}[OpenShift Console^]
. Navigate to the *Topology* view in the `rhdh` project
. Verify all Developer Hub pods are `Running`

Direct link: https://console-openshift-console.{openshift_cluster_ingress_domain}/topology/ns/rhdh?view=graph[Topology (rhdh)^]

=== Verify with CLI

[source,bash,subs="attributes"]
----
oc get pods -n rhdh -w
----

TIP: The `-w` flag watches for changes in real-time. Press **Ctrl+C** to stop watching once all pods report `Running` and `1/1` or `2/2` READY.
