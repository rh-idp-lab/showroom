= Configure Platform RBAC
:navtitle: Configure RBAC

Users need access to their own namespaces, view access to GitLab (for pipelines), and read access to ArgoCD namespaces (`openshift-gitops`, `rhdh-gitops`) to see application status. The RBAC chart creates RoleBindings that grant these permissions per team.

== The Helm Chart

The ArgoCD Application points to the `rbac` chart in your GitLab repository.
Browse it here: {helm_repo_browse}/-/tree/{helm_repo_tag}/rbac[{helm_repo_browse}/-/tree/{helm_repo_tag}/rbac^]

The chart creates the `ClusterRoles`, `RoleBindings`, and `Groups` that define access control across platform namespaces.

== Create the ArgoCD Application

Create the ArgoCD Application for RBAC:

[source,bash,subs="attributes"]
----
cat <<'EOF' > rbac-app.yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: rbac
  namespace: openshift-gitops
spec:
  project: default
  source:
    repoURL: {helm_repo}
    targetRevision: {helm_repo_tag}
    path: rbac
    helm:
      values: |
        rbac:
          - namespace: devteam1
            subjects:
              - kind: Group
                name: devteam1
                role: admin
          - namespace: gitlab
            subjects:
              - kind: Group
                name: developers
                role: view
              - kind: Group
                name: platformengineers
                role: admin
          - namespace: openshift-gitops
            subjects:
              - kind: Group
                name: platformengineers
                role: admin
              - kind: Group
                name: developers
                role: view
          - namespace: rhdh-gitops
            subjects:
              - kind: Group
                name: platformengineers
                role: admin
              - kind: Group
                name: developers
                role: view
  destination:
    server: https://kubernetes.default.svc
    namespace: openshift-gitops
  syncPolicy:
    automated:
      prune: true
      selfHeal: true
EOF
----

Apply the Application:

[source,bash]
----
oc apply -f rbac-app.yaml -n openshift-gitops
----

== Verify RoleBindings

Confirm RoleBindings were created:

[source,bash]
----
oc get rolebindings -n gitlab
----

You should see bindings for `developers` (view) and `platformengineers` (admin). Check other namespaces:

[source,bash]
----
oc get rolebindings -n openshift-gitops
oc get rolebindings -n rhdh-gitops
----
