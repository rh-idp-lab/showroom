== Terminal Access

The terminal on the right side of this page is connected to a bastion host with `oc`, `helm`, and other CLI tools pre-installed.

Verify your access:

[source,bash,subs="attributes"]
----
oc whoami
oc get nodes
----

You should see your cluster nodes listed. If not, log in:

[source,bash,subs="attributes"]
----
oc login -u {ssh_user} -p {ssh_password}
----
