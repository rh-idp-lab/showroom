== Terminal access

The **Terminal** tab on the right side of this page provides an in-browser terminal connected directly to your OpenShift cluster. It is pre-authenticated as a cluster administrator: no `oc login` required.

Verify your access:

[source,bash,subs="attributes"]
----
oc whoami
oc get nodes
----

You should see the cluster service account and your cluster nodes listed. All `oc`, `helm`, and `git` commands run directly from this terminal throughout the lab.
