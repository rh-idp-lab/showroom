= Deploy Red Hat Trusted Artifact Signer
:navtitle: Deploy Trusted Artifact Signer

Red Hat Trusted Artifact Signer (RHTAS) provides Sigstore-based artifact signing for supply chain security. It enables developers to sign container images and verify provenance.

== The Helm Chart

The ArgoCD Application points to the `rhtas` chart in your GitLab repository.
Browse it here: {helm_repo_browse}/-/tree/{helm_repo_tag}/rhtas[{helm_repo_browse}/-/tree/{helm_repo_tag}/rhtas^]

The chart installs the Trusted Artifact Signer operator (via OLM) and a `SecureSign` instance that provisions the Fulcio CA, Rekor transparency log, and Cosign tooling.

== Create the ArgoCD Application

[source,bash,subs="attributes"]
----
cat <<'EOF' > trusted-artifact-signer-app.yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: trusted-artifact-signer
  namespace: openshift-gitops
spec:
  project: default
  source:
    repoURL: {helm_repo}
    path: rhtas
    targetRevision: {helm_repo_tag}
    helm:
      values: |
        oidcIssuer: https://sso.{openshift_cluster_ingress_domain}/realms/backstage
        email: admin@example.com
        organization: my-org
        instanceName: tas
        namespace: trusted-artifact-signer
  destination:
    server: https://kubernetes.default.svc
    namespace: trusted-artifact-signer
  syncPolicy:
    automated: {}
    syncOptions:
      - CreateNamespace=true
EOF
----

== Apply and verify

[source,bash,subs="attributes"]
----
oc apply -f trusted-artifact-signer-app.yaml
oc get pods -n trusted-artifact-signer
----

== Integration with Tekton pipelines

TAS integrates with OpenShift Pipelines so that Tekton tasks can sign container images automatically. Configure your pipeline tasks to use the Sigstore signing service; signed artifacts are then verifiable for supply chain compliance.
