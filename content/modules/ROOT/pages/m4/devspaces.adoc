= Deploy Red Hat OpenShift Dev Spaces
:navtitle: Deploy Dev Spaces

Red Hat OpenShift Dev Spaces provides a cloud-based IDE for developers with pre-configured workspaces, Git integration, and terminal access — all in the browser.

== Why Dev Spaces?

In a traditional setup, onboarding a developer takes hours: install the right versions of `node`, `python`, `oc`, `helm`, configure git credentials, clone repositories, set up environment variables. Every developer ends up with a slightly different environment — "works on my machine" becomes a real problem.

Dev Spaces eliminates this entirely:

* **Zero local setup** — developers open a browser, click a link, and land in a fully configured IDE running inside the cluster. No installation required.
* **Reproducible environments** — workspaces are defined as code (`devfile.yaml` in the repository). Every developer gets the exact same toolchain, every time.
* **Direct cluster access** — the IDE runs inside OpenShift. No VPN, no port-forwarding, no firewall issues. The terminal has direct access to the cluster.
* **Git integration via OAuth** — Dev Spaces authenticates to GitLab using an OAuth application. Developers push code without managing SSH keys or tokens manually.
* **Consistent security posture** — code stays inside the cluster. No source code on laptops, no credentials in `~/.gitconfig` on personal machines.
* **SSO via Keycloak** — developers log in once using their platform identity. No separate Dev Spaces account.

In the context of an IDP, Dev Spaces is the "cloud IDE" golden path: any developer can start contributing to any project in seconds, with the correct toolchain, access rights, and integrations already configured.

== The Helm Chart

The ArgoCD Application points to the `devspaces` chart in your GitLab repository.
Browse it here: {helm_repo_browse}/-/tree/{helm_repo_tag}/devspaces[{helm_repo_browse}/-/tree/{helm_repo_tag}/devspaces^]

The chart installs the Dev Spaces operator (via OLM) and a `CheCluster` instance pre-configured with the Keycloak OAuth integration.

== Step 1 — Create a GitLab OAuth Application

Dev Spaces needs a GitLab OAuth application to authenticate developers and allow them to clone and push to repositories.

. Open https://gitlab-gitlab.{openshift_cluster_ingress_domain}[GitLab^] and log in as `root` / `{common_password}`
. Navigate to *Admin Area* (wrench icon, top right) → *Applications*
. Click *New application* and fill in:
+
[cols="1,3",options="header"]
|===
|Field |Value

|*Name*
|`devspaces`

|*Redirect URI*
|`https://devspaces.{openshift_cluster_ingress_domain}/api/oauth/callback`

|*Scopes*
|`api`, `read_user`, `read_repository`, `write_repository`, `openid`, `profile`, `email`

|*Trusted*
|✓ Check this box
|===

. Click *Save application*
. Copy the **Application ID** and **Secret** — these values are shown only once

Save them in environment variables in your terminal:

[source,bash,subs="attributes"]
----
export GITLAB_OAUTH_ID=<paste Application ID here>
export GITLAB_OAUTH_SECRET=<paste Secret here>
----

== Step 2 — Create the ArgoCD Application

Use the OAuth credentials to generate the Dev Spaces Application manifest:

[source,bash,subs="attributes"]
----
cat <<EOF > devspaces-app.yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: devspaces
  namespace: openshift-gitops
  finalizers:
    - resources-finalizer.argocd.argoproj.io/foreground
spec:
  project: default
  source:
    repoURL: {helm_repo}
    path: devspaces
    targetRevision: {helm_repo_tag}
    helm:
      values: |
        devspaces:
          gitlab:
            url: https://gitlab-gitlab.{openshift_cluster_ingress_domain}
            oauthClientId: $GITLAB_OAUTH_ID
            oauthClientSecret: $GITLAB_OAUTH_SECRET
  destination:
    server: https://kubernetes.default.svc
    namespace: openshift-devspaces
  syncPolicy:
    automated:
      prune: true
      selfHeal: true
    retry:
      backoff:
        duration: 5s
        factor: 2
        maxDuration: 3m0s
      limit: 5
    syncOptions:
      - CreateNamespace=true
      - RespectIgnoreDifferences=true
EOF
----

Apply it:

[source,bash]
----
oc apply -f devspaces-app.yaml
----

== Step 3 — Verify the Deployment

[source,bash,subs="attributes"]
----
oc get pods -n openshift-devspaces
----

You can also track progress in the https://openshift-gitops-server-openshift-gitops.{openshift_cluster_ingress_domain}[ArgoCD UI^] under the `devspaces` application.

In the OpenShift Console:

. Navigate to *Ecosystem → Installed Operators*
. Select the `openshift-devspaces` project
. Confirm **Red Hat OpenShift Dev Spaces** appears with status `Succeeded`

== Step 4 — Access Dev Spaces

Once all pods are running, open: https://devspaces.{openshift_cluster_ingress_domain}[Dev Spaces^]

Log in with your GitLab credentials — Dev Spaces will redirect you to GitLab OAuth and then open your workspace.
