= Explore Red Hat Build of Keycloak
:navtitle: Explore Keycloak (RHBK)

Red Hat Build of Keycloak provides **single sign-on (SSO)** for the entire platform. Developer Hub, Dev Spaces, and ArgoCD all authenticate users through Keycloak, eliminating separate logins and centralizing identity management.

Keycloak is already deployed and configured in your cluster as part of the pre-installed foundation.

== Verify the Installation

Check that Keycloak pods are running and the realm import completed:

[source,bash,subs="attributes"]
----
oc get pods -n keycloak
oc get keycloakrealmimport -n keycloak
----

The `sso` realm should show `Reconciled`.

Confirm the operator is installed in the OpenShift Console:

. Open the https://console-openshift-console.{openshift_cluster_ingress_domain}[OpenShift Console^]
. Navigate to *Ecosystem → Installed Operators*
. Select the `keycloak` project
. Confirm **Red Hat Build of Keycloak** appears with status `Succeeded`

== Explore Keycloak

Open the Keycloak admin console: https://sso.{openshift_cluster_ingress_domain}[https://sso.{openshift_cluster_ingress_domain}^]

Log in with `admin` / `{common_password}`, then navigate to the **sso** realm and explore:

[cols="1,3",options="header"]
|===
|Section |What to look at

|*Clients*
|`backstage`, `backstage-plugin`, and `openshift` — OAuth clients pre-configured for Developer Hub and Dev Spaces

|*Users*
|Platform users pre-created by the realm import (e.g., `user1`, `user2`)

|*Groups*
|RBAC groups: `admins`, `users`

|*Realm settings → Identity Providers*
|OpenShift identity provider — allows users to log in with their OCP credentials
|===
