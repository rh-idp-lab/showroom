= Explore Vault
:navtitle: Explore Vault

HashiCorp Vault provides **centralized secrets management** for the IDP. Application secrets (API keys, passwords, certificates) are stored in Vault and injected into Kubernetes via External Secrets Operator (deployed in Module 2).

== Vault's Role in the IDP

* Store secrets once in Vault
* External Secrets Operator syncs them into Kubernetes `Secret` objects
* Applications consume secrets as environment variables or mounted files
* No secrets in Git; rotation and audit trail in Vault

== Check Vault Status

[source,bash,subs="attributes"]
----
oc get pods -n vault
oc exec -n vault vault-0 -- vault status
----

The Vault pod should be `Running`. `vault status` reports sealed/unsealed and cluster health.

== KV Secrets Engine

This lab uses the **KV (Key-Value) secrets engine**. Secrets are stored at paths like:

`kv/secrets/rhdh/...`

Each platform component can have its own path (e.g., `kv/secrets/rhdh/backstage` for Developer Hub config).

== Path Structure

[cols="1,3",options="header"]
|===
|Path |Purpose

|`kv/secrets/rhdh/...`
|Secrets for Red Hat Developer Hub, Keycloak, Dev Spaces, etc.
|===

In Module 3, you will store Keycloak and other secrets in Vault. External Secrets Operator (Module 2) will sync them into cluster namespaces.
